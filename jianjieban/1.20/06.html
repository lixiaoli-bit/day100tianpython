🐍 循环结构

for-in · while · break · continue · 重复执行的艺术

我们在写程序的时候，极有可能遇到需要重复执行某条或某些指令的场景。为了应对这些场景，我们可以在 Python 程序中使用循环结构。所谓循环结构，就是程序中控制某条或某些指令重复执行的结构。在 Python 语言中构造循环结构有两种做法，一种是 for-in 循环，另一种是 while 循环。

for-in 循环

如果明确知道循环执行的次数，我们推荐使用 for-in 循环。例如，每隔 1 秒输出一次 “hello, world”，持续 1 小时：

# 使用 for-in 循环重复 3600 次 import time for _ in range(3600): print('hello, world') time.sleep(1)
💡 range 函数用法：
• range(101) → 0~100
• range(1, 101) → 1~100（左闭右开）
• range(1, 101, 2) → 1,3,5,...,99（步长2）
• range(100, 0, -2) → 100,98,...,2（递减）

📐 例：1 到 100 求和

total = 0 for i in range(1, 101): total += i print(total) # 5050

📐 例：1 到 100 偶数求和

total = 0 for i in range(2, 101, 2): total += i print(total)

更简洁的方式：print(sum(range(2, 101, 2)))

while 循环

如果要构造循环结构但是又不能确定循环重复的次数，我们推荐使用 while 循环。它通过布尔值或能产生布尔值的表达式来控制循环，当条件为 True 时循环体重复执行，为 False 时结束。

# while 循环实现 1 到 100 求和 total = 0 i = 1 while i <= 100: total += i i += 1 print(total)

break 与 continue

⛔ break

终止当前循环结构，跳出循环。

while True: if i > 100: break total += i i += 2

⏭️ continue

跳过本轮循环后续代码，直接进入下一轮。

for i in range(1, 101): if i % 2 != 0: continue total += i

嵌套循环

循环结构可以嵌套，即循环体内部还可以包含循环。下面的例子通过嵌套循环输出乘法口诀表（九九表）。

for i in range(1, 10): for j in range(1, i + 1): print(f'{i}×{j}={i * j}', end='\t') print()
📌 输出效果： 外层循环控制行，内层循环控制列，每行结束后通过 print() 换行。

应用实例

🔢 例1：判断素数

输入大于 1 的正整数，判断是否为素数（只能被 1 和自身整除）。

num = int(input('请输入一个正整数: ')) end = int(num ** 0.5) is_prime = True for i in range(2, end + 1): if num % i == 0: is_prime = False break print(f'{num}是素数' if is_prime else f'{num}不是素数')

📐 例2：最大公约数（欧几里得算法）

输入两个正整数，用辗转相除法求最大公约数。

x = int(input('x = ')) y = int(input('y = ')) while y % x != 0: x, y = y % x, x print(f'最大公约数: {x}')
⚡ 算法对比： 从大到小遍历效率低，欧几里得算法（辗转相除法）更快，尤其适用于大数互质的情况。

🎯 例3：猜数字游戏

计算机生成 1~100 随机数，玩家猜数字，提示“大一点”或“小一点”，猜中后显示次数。

import random answer = random.randrange(1, 101) counter = 0 while True: counter += 1 num = int(input('请输入: ')) if num < answer: print('大一点.') elif num > answer: print('小一点.') else: print('猜对了!') break print(f'你一共猜了{counter}次.')
random.randrange 无限循环 + break 计数器

📌 总结

  • 明确次数 → for-in；不确定次数 → while。
  • break 终止整个循环，continue 跳过本轮后续代码。
  • 循环可以嵌套，如打印九九乘法表。
  • 应用实例：素数判断、最大公约数（欧几里得算法）、猜数字游戏。
🚀 循环结构让程序拥有强大的重复执行能力，结合分支结构，可以解决绝大多数实际问题！
