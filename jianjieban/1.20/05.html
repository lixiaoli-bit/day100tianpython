🐍 分支结构

if · elif · else · match · case · 选择与决策

迄今为止，我们写的 Python 程序都是一条一条语句按顺序向下执行的，这种代码结构叫做顺序结构。然而仅有顺序结构并不能解决所有的问题，比如我们设计一个游戏，游戏第一关的过关条件是玩家获得 1000 分，那么在第一关完成后，我们要根据玩家得到的分数来决定是进入第二关，还是告诉玩家“Game Over”。在这种场景下，我们的代码就会产生两个分支，而且只有一个会被执行。我们将这种结构称之为“分支结构”或“选择结构”。

if 与 else 构造分支

在 Python 中，构造分支结构最常用的是 if、elif 和 else 三个关键字。下面以 BMI 计算器为例，展示分支结构的用法。

📊 BMI 计算器 (v1.0) — 简单 if

公式：BMI = 体重(kg) / (身高(m))²，正常范围 18.5 ≤ BMI < 24。

height = float(input('身高(cm)：')) weight = float(input('体重(kg)：')) bmi = weight / (height / 100) ** 2 print(f'{bmi = :.1f}') if 18.5 <= bmi < 24: print('你的身材很棒！')
if 条件 缩进代码块
💡 缩进与代码块： Python 使用缩进表示代码层次，if 条件成立时，下方缩进的语句会被执行。通常使用 4 个空格，不要使用 Tab 键。

📊 BMI 计算器 (v1.1) — if + else

if 18.5 <= bmi < 24: print('你的身材很棒！') else: print('你的身材不够标准哟！')

📊 BMI 计算器 (v1.2) — if + elif + else

if bmi < 18.5: print('你的体重过轻！') elif bmi < 24: print('你的身材很棒！') elif bmi < 27: print('你的体重过重！') elif bmi < 30: print('你已轻度肥胖！') elif bmi < 35: print('你已中度肥胖！') else: print('你已重度肥胖！')
多分支 条件互斥

match 与 case — 模式匹配

Python 3.10 引入了 match 和 case 关键字，提供更优雅的多分支结构。以下是对 HTTP 状态码进行分类的例子。

🔹 if-elif 版本

if status == 400: desc = 'Bad Request' elif status == 401: desc = 'Unauthorized' elif status == 403: desc = 'Forbidden' elif status == 404: desc = 'Not Found' else: desc = 'Unknown'

🔸 match-case 版本

match status: case 400: desc = 'Bad Request' case 401: desc = 'Unauthorized' case 403: desc = 'Forbidden' case 404: desc = 'Not Found' case _: desc = 'Unknown'
📌 通配符 case _： 类似 switch 中的 default，匹配所有未覆盖的情况。可以合并多个模式，如 case 401 | 403 | 404。

应用实例

📐 例1：分段函数求值

y = 3x-5 (x>1) ｜ y = x+2 (-1≤x≤1) ｜ y = 5x+3 (x<-1)

x = float(input('x = ')) if x > 1: y = 3 * x - 5 elif x >= -1: y = x + 2 else: y = 5 * x + 3 print(f'{y = }')
💡 扁平 vs 嵌套： Python 之禅说 “Flat is better than nested”，尽量让分支扁平化，避免深层嵌套。

📝 例2：百分制成绩转等级

A (≥90) ｜ B (≥80) ｜ C (≥70) ｜ D (≥60) ｜ E (<60)

score = float(input('请输入成绩: ')) if score >= 90: grade = 'A' elif score >= 80: grade = 'B' elif score >= 70: grade = 'C' elif score >= 60: grade = 'D' else: grade = 'E' print(f'{grade = }')

📐 例3：判断三角形并计算周长面积

输入三边，判断是否构成三角形，若成立则用海伦公式计算面积。

a = float(input('a = ')) b = float(input('b = ')) c = float(input('c = ')) if a + b > c and a + c > b and b + c > a: perimeter = a + b + c s = perimeter / 2 area = (s * (s - a) * (s - b) * (s - c)) ** 0.5 print(f'周长: {perimeter}') print(f'面积: {area}') else: print('不能构成三角形')
海伦公式 条件组合

嵌套分支

在 if、elif 或 else 代码块中再构造分支，称为嵌套分支。但为了可读性，应尽量避免过深嵌套。

# 分段函数求值（嵌套写法） if x > 1: y = 3 * x - 5 else: if x >= -1: y = x + 2 else: y = 5 * x + 3

📌 总结

  • 分支结构通过 if、elif、else 实现，Python 使用缩进区分代码块。
  • Python 3.10+ 支持 match 和 case 实现模式匹配，代码更简洁。
  • 分支结构可以嵌套，但应保持扁平化，提高可读性。
  • 实际应用：BMI 计算、分段函数、成绩转换、三角形判断等。
