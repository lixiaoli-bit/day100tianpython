在上一课中，我们对 Python 语言的过去现在有了一些了解，并准备好了运行 Python 程序所需要的解释器环境。相信大家已经迫不及待想开始自己的 Python 编程之旅了，但是新问题来了：我们应该在什么地方书写 Python 程序，然后又怎么运行它呢？

编写代码的工具

下面为大家讲解几种可以编写和运行 Python 代码的工具，可以根据自己的需求来选择。对于初学者，我个人比较推荐使用 PyCharm，因为它不需要太多的配置也非常的强大，对新手还是很友好的。如果你也听说过或者喜欢 PyCharm，可以直接快进到讲解 PyCharm 的部分。

📟 默认的交互式环境

打开 Windows 的“命令提示符”或“PowerShell”工具，输入 python 然后按下 Enter 键，这个命令会把我们带到一个交互式环境中。输入一行代码并按下 Enter 键，代码马上会被执行，如果代码有产出结果，那么结果会被显示在窗口中。

Python 3.10.10 Type "help", "copyright", "credits" or "license" for more information. >>> 2 * 3 6 >>> 2 + 3 5 >>>
💡 说明： 使用 macOS 系统的用户需要打开“终端”工具，输入 python3 进入交互式环境。如果希望退出交互式环境，可以在交互式环境中输入 quit()。

⚡ 更好的交互式环境 – IPython

默认的交互式环境用户体验并不怎么好。我们可以用 IPython 来替换掉它，因为 IPython 提供了更为强大的编辑和交互功能。可以使用 Python 的包管理工具 pip 来安装 IPython：

# 安装 IPython（建议先配置国内镜像源） pip install ipython

安装后，使用 ipython 命令启动交互式环境。

📦 提示： 在使用上面的命令安装 IPython 之前，可以先通过 pip config set global.index-url https://pypi.doubanio.com/simple 将下载源修改为国内镜像，否则下载安装的过程可能会非常缓慢。

📝 文本编辑神器 – Visual Studio Code

Visual Studio Code 是由微软开发，能够在 Windows、Linux 和 macOS 等操作系统上运行的代码编辑神器。它支持语法高亮、自动补全、多点编辑、运行调试等一系列便捷功能，且支持多种编程语言。如果大家要选择一款高级文本编辑工具，强烈推荐 Visual Studio Code。

🧰 集成开发环境 – PyCharm

如果用 Python 语言开发商业项目，推荐使用更为专业的工具 PyCharm。PyCharm 是由 JetBrains 公司针对 Python 语言提供的集成开发环境（IDE），提供了编写代码、运行代码、调试代码、分析代码、版本控制等一系列强大功能和便捷操作。

Community 免费版 Professional 专业版 (30天试用) 功能强大，对新手友好 推荐初学者使用

📥 安装与首次运行 (Windows / macOS)

  1. 从 PyCharm 下载页面 下载对应操作系统安装包。
  2. 运行安装程序，勾选 “创建桌面快捷方式” 和 “在右键菜单中添加 Open Folder as Project” (Windows)。
  3. 首次运行选择 “Do not import settings” (不导入设置)。
  4. 在欢迎界面点击 Customize 可进行个性化设置，如主题、字体等。
  5. 点击 New Project 创建项目，指定项目路径，PyCharm 会自动检测 Python 解释器并创建虚拟环境。
  6. 在项目文件夹上右键 → New → Python File，命名后即可编写代码。
  7. 编写代码后，右键 → Run 运行，下方 Run 窗口显示结果。
✔ 自动检测解释器 ✔ 虚拟环境 ✔ 一键运行
💡 每日小贴士： PyCharm 有一个 “每日小贴士” 弹窗，会教给你一些使用技巧。如果不需要，直接关闭即可；如果不希望它再次出现，在关闭前勾选 “Don't show tips on startup”。

🌍 你好世界

按照行业惯例，我们学习任何一门编程语言写的第一个程序都是输出 hello, world。下面是对应的 Python 语言版本：

print('hello, world')

上面的代码只有一个语句，用到了 print 函数，它可以帮助我们输出指定的内容；'hello, world' 是一个字符串。在 Python 中，我们可以用单引号或双引号来表示一个字符串。

⚠️ 注意： 代码中的圆括号、单引号都是在英文输入法状态下输入的，如果不小心写成了中文的圆括号或单引号，运行代码时会出现 SyntaxError: invalid character 这样的错误提示。

不同于 C、C++ 或 Java，Python 代码中的语句不需要用分号来表示结束，也就是说，如果我们想再写一条语句，只需要回车换行即可：

print('hello, world') print('goodbye, world')

如果不使用 PyCharm，我们也可以直接调用 Python 解释器来运行 Python 程序。将上面的代码保存为 example01.py 文件，然后在命令行中运行：

# Windows python C:\code\example01.py # macOS / Linux python3 /Users/yourname/example01.py
💡 小技巧： 如果路径比较长，可以通过拖拽文件到“命令提示符”或“终端”中，会自动输入完整的文件路径。

📝 注释你的代码

注释是编程语言的重要组成部分，用于解释代码的作用，增强可读性。也可以将暂时不需要运行的代码段通过注释来去掉。Python 中有两种形式的注释：

  • 单行注释：以 # 和空格开头，可以注释掉从 # 开始后面一整行的内容。
  • 多行注释：三个引号（通常用双引号）开头，三个引号结尾，通常用于添加多行说明性内容。
""" 第一个Python程序 - hello, world Version: 1.0 Author: 骆昊 """ # print('hello, world') print("你好，世界！")

  • 注释让代码更容易看懂，但不会影响执行结果。
