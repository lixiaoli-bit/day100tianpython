🐍 Python 语言中的运算符

算术 · 赋值 · 比较 · 逻辑 · 表达式实战

Python 语言支持很多种运算符，有了变量和运算符，我们就可以构造各种各样的表达式来解决实际问题。在计算机科学中，表达式是计算机程序中的句法实体，它由一个或多个常量、变量、函数和运算符组合而成。不管使用什么样的编程语言，构造表达式都是非常重要的。

算术运算符

Python 中的算术运算符非常丰富，包括加、减、乘、除、整除、求模（余数）和求幂。

# 算术运算符示例 print(321 + 12) # 333 print(321 - 12) # 309 print(321 * 12) # 3852 print(321 / 12) # 26.75 print(321 // 12) # 26 (整除) print(321 % 12) # 9 (余数) print(321 ** 12) # 幂运算

算术运算遵循先乘除后加减，求幂优先级高于乘除。使用圆括号可以改变优先级：

# 优先级演示 print(2 + 3 * 5) # 17 print((2 + 3) * 5) # 25 print((2 + 3) * 5 ** 2) # 125 print(((2 + 3) * 5) ** 2) # 625

赋值运算符

赋值运算符 = 将右边的值赋给左边的变量。复合赋值运算符如 +=、-= 等，可以简化代码。

# 赋值与复合赋值 a = 10 b = 3 a += b # a = a + b a *= a + 2 # a = a * (a + 2) print(a) # 大家算一下这里会输出什么
🐘 海象运算符 :=： Python 3.8 引入，可以将值赋给变量，同时该值作为表达式的结果。例如 print((a := 10)) 会输出 10。但要注意 print(a = 10) 会引发语法错误。

比较运算符与逻辑运算符

比较运算符包括 ==、!=、<、>、<=、>=，结果均为布尔值（True / False）。逻辑运算符 and、or、not 用于组合布尔值，支持短路求值。

# 比较与逻辑运算 flag0 = 1 == 1 # True flag1 = 3 > 2 # True flag2 = 2 < 1 # False flag3 = flag1 and flag2 # False flag4 = flag1 or flag2 # True flag5 = not flag0 # False print(flag0, flag1, flag2, flag3, flag4, flag5) print(flag1 and not flag2) # True print(1 > 2 or 2 == 3) # False

应用实例

🌡️ 例1：华氏温度转摄氏温度

公式：C = (F - 32) / 1.8

f = float(input('请输入华氏温度: ')) c = (f - 32) / 1.8 print(f'{f:.1f}华氏度 = {c:.1f}摄氏度')
input float f-string

⭕ 例2：计算圆的周长和面积

半径 r，周长 2πr，面积 πr²，使用 math.pi 获取圆周率。

import math radius = float(input('请输入圆的半径: ')) perimeter = 2 * math.pi * radius area = math.pi * radius ** 2 print(f'周长: {perimeter:.2f}') print(f'面积: {area:.2f}')

Python 3.8+ 支持 f'{perimeter = :.2f}' 同时输出变量名和值。

📅 例3：判断闰年

公历闰年规则：能被4整除但不能被100整除，或者能被400整除。

year = int(input('请输入年份: ')) is_leap = year % 4 == 0 and year % 100 != 0 or year % 400 == 0 print(f'{is_leap = }')
📌 注意： 格里历（公历）于1582年引入，输入年份应在此之后。逻辑组合中 and 优先级高于 or，但此处用括号更加清晰。

  • 赋值运算符（包括复合赋值）和比较/逻辑运算符是编写条件逻辑的基础。
