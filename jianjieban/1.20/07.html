🐍 分支与循环 · 实战

素数 · 斐波那契 · 水仙花数 · 百钱百鸡 · Craps 赌博游戏

分支结构和循环结构是构造程序逻辑的基础，它们的重要性不言而喻。看懂别人的代码很容易，但是要自己写出类似的代码却又很难。只要加强编程练习，通过量的积累来产生质的变化，这个问题迟早都会解决的。下面我们通过几个经典案例来巩固分支与循环的运用。

📐 例1：100以内的素数

素数指的是只能被 1 和自身整除的正整数（不包括 1）。

# 输出100以内的素数 for num in range(2, 100): is_prime = True for i in range(2, int(num ** 0.5) + 1): if num % i == 0: is_prime = False break if is_prime: print(num)
💡 优化： 只需检查到 √num 即可，因子成对出现，可大幅减少循环次数。

📐 例2：斐波那契数列

输出斐波那契数列中的前 20 个数。数列特点：前两个数为 1，从第三个数开始，每个数都是前两个数之和。

# 输出斐波那契数列前20项 a, b = 0, 1 for _ in range(20): a, b = b, a + b print(a)
📌 递推赋值： a, b = b, a + b 先计算右侧，再同时赋值给左侧，简洁高效。

📐 例3：水仙花数

找出 100 到 999 范围内的所有水仙花数（各位数字的立方和等于该数本身）。

# 三位水仙花数 for num in range(100, 1000): low = num % 10 mid = num // 10 % 10 high = num // 100 if num == low ** 3 + mid ** 3 + high ** 3: print(num)

利用 // 和 % 拆分数字是常见技巧，也可用于整数反转：

# 正整数反转 num = int(input('num = ')) reversed_num = 0 while num > 0: reversed_num = reversed_num * 10 + num % 10 num //= 10 print(reversed_num)

📐 例4：百钱百鸡问题

公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元三只，用 100 元买 100 只鸡，求各多少只。

🧮 穷举法（暴力搜索）

for x in range(0, 21): for y in range(0, 34): z = 100 - x - y if z % 3 == 0 and 5 * x + 3 * y + z // 3 == 100: print(f'公鸡: {x}只, 母鸡: {y}只, 小鸡: {z}只')
穷举法 循环优化 条件筛选
⚡ 优化思路： 由 x + y + z = 100 可得 z = 100 - x - y，将三层循环降为两层，效率大幅提升。

🎲 例5：CRAPS 赌博游戏

玩家初始 1000 元，每局下注。第一次摇出 7 或 11 玩家胜，摇出 2、3、12 庄家胜；否则继续摇，若摇出 7 庄家胜，若摇出首次点数玩家胜，否则继续。

# Craps 赌博游戏（核心逻辑） import random money = 1000 while money > 0: print(f'总资产: {money}元') debt = int(input('请下注: ')) first_point = random.randrange(1, 7) + random.randrange(1, 7) print(f'玩家摇出了{first_point}点') if first_point in (7, 11): money += debt print('玩家胜!\n') elif first_point in (2, 3, 12): money -= debt print('庄家胜!\n') else: while True: cur = random.randrange(1, 7) + random.randrange(1, 7) print(f'玩家摇出了{cur}点') if cur == 7: money -= debt print('庄家胜!\n') break elif cur == first_point: money += debt print('玩家胜!\n') break print('你破产了, 游戏结束!')
🎯 要点： 外层 while 控制游戏进行，内层 while 处理追加摇骰。使用 in 运算符简化多个条件的判断。
