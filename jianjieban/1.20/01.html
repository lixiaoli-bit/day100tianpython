安装 Python 环境

工欲善其事，必先利其器。推荐安装官方的 Python 3 解释器（CPython）。从 Python 官网下载页面 根据操作系统选择合适的安装程序。

Download Python 3.10.10 / 3.10.11 提供 Windows/macOS 安装包，其他版本可能只有源代码。 推荐使用安装程序

🪟 Windows 环境

📥 安装步骤 (Windows 11)

  1. 勾选 Add python.exe to PATH 和 Use admin privileges when installing py.exe。
  2. 选择 Customize Installation（自定义安装）。
  3. 可选特性全选（尤其是 pip 包管理工具）。
  4. 高级选项勾选 Add Python to environment variables 和 Precompile standard library。
  5. 自定义安装路径（不要包含中文、空格或特殊字符）。
  6. 点击 Install 安装，等待成功（关键词 successful）。
✔ 勾选 PATH ✔ 自定义安装 ✔ 预编译标准库
# 检查 Python 版本 (Windows) python --version # 检查 pip 版本 pip --version
⚠️ 安装失败？ 可能缺少动态链接库或构建工具，可下载 “Visual Studio 2022 生成工具” 修复，勾选对应选项联网修复。

🍎 macOS 环境

📥 安装步骤

从官网下载 .pkg 文件，双击运行，不断点击“继续”即可完成安装，几乎无需设置。

# 检查 Python 版本 (macOS) python3 --version # 检查 pip3 版本 pip3 --version

注意：macOS 上命令是 python3 和 pip3。

📌 总结

  • Python 语言很强大，值得学习。
  • 首先安装 Python 环境（解释器）。
  • Windows: python --version ；macOS: python3 --version
