🐍 Python 语言中的变量

数据类型 · 变量命名 · 类型转换

程序是数据和指令的有序集合，写程序就是用数据和指令控制计算机做我们想让它做的事情。相较于 C、C++、Java 等编程语言，Python 对初学者和非专业人士更加友好，很多问题在 Python 中都能找到简单优雅的解决方案。接下来，我们就从最基础的语言元素开始，带大家认识和使用 Python 语言。

一些常识

计算机硬件系统通常由五大部件构成：运算器、控制器、存储器、输入设备和输出设备。运算器和控制器合称 中央处理器（CPU），负责执行各种运算和控制指令。程序是指令的集合，写程序就是将指令组织起来控制计算机。存储器分为内部存储器（内存）和外部存储器，程序执行时数据和指令需要加载到内存中。目前计算机大多遵循“冯·诺依曼体系结构”，其关键点是：将存储器与中央处理器分开，以及将数据以二进制方式编码。

💡 二进制小知识： 计算机使用二进制计数，因为物理器件上最容易实现（高电压表示1，低电压表示0）。虽然大多数时候不需要深入理解进制转换，但了解计算机内部以二进制存储数据，有助于理解后续的类型与运算。

变量和类型

在编程语言中，变量是数据的载体，是一块用来保存数据的内存空间，变量的值可以被读取和修改。Python 中预设了多种数据类型，常用的有以下几种：

📦 常用数据类型

  • 整型 (int) — 任意大小的整数，支持二进制、八进制、十进制、十六进制表示法。
  • 浮点型 (float) — 小数，支持科学计数法（如 1.23456e2）。
  • 字符串型 (str) — 以单引号或双引号包裹的任意文本。
  • 布尔型 (bool) — 只有 True 和 False 两种值，表示“真”与“假”。
int float str bool

下面的代码演示了不同进制整数的表示：

# 二进制、八进制、十进制、十六进制 print(0b100) # 4 print(0o100) # 64 print(100) # 100 print(0x100) # 256

浮点数同样可以使用科学计数法：

print(123.456) # 数学写法 print(1.23456e2) # 科学计数法 → 123.456

变量命名规则与惯例

每个变量都需要有一个名字，Python 中变量命名需要遵循以下规则和惯例。

📐 规则（必须遵守）

  • 由字母、数字、下划线构成，数字不能开头。
  • 大小写敏感（A 和 a 不同）。
  • 不能与 Python 关键字重名，尽量避开保留字。

✍️ 惯例（强烈建议）

  • 小写字母，多个单词用下划线连接（如 user_name）。
  • 受保护的变量用单下划线开头（_protected）。
  • 私有的变量用双下划线开头（__private）。
💡 见名知意： 变量名应清晰表达其用途，例如 age、total_score 比 a、ts 更具可读性，这是专业程序员的基本素养。

变量的使用

通过例子来说明变量的定义、运算和类型检查。

# 定义变量并进行加减乘除 a = 45 b = 12 print(a, b) # 45 12 print(a + b) # 57 print(a - b) # 33 print(a * b) # 540 print(a / b) # 3.75

使用 type() 函数可以检查变量的类型：

a = 100 b = 123.45 c = 'hello, world' d = True print(type(a)) # <class 'int'> print(type(b)) # <class 'float'> print(type(c)) # <class 'str'> print(type(d)) # <class 'bool'>

🔄 类型转换

Python 内置了多个类型转换函数，常用的有：

int() float() str() chr() ord()
# 类型转换示例 a = 100 b = 123.45 c = '123' d = '100' e = '123.45' f = 'hello, world' g = True print(float(a)) # 100.0 print(int(b)) # 123 print(int(c)) # 123 print(int(c, base=16)) # 291 (十六进制解析) print(int(d, base=2)) # 4 (二进制解析) print(float(e)) # 123.45 print(bool(f)) # True (非空字符串) print(int(g)) # 1 print(chr(a)) # 'd' print(ord('d')) # 100
📌 补充说明： str 转 int 时可通过 base 指定进制；bool 转 int 时 True → 1，False → 0；非空字符串转布尔值均为 True。

📌 总结

  • 变量用于保存数据，Python 中常用类型：int、float、str、bool。
  • 变量命名需遵循规则（字母数字下划线、不能以数字开头、大小写敏感），并尽量做到“见名知意”。
  • 使用 type() 可检查变量类型，使用 int()、float()、str() 等可进行类型转换。
  • 变量是可以做运算的，这是解决很多问题的先决条件，下一课将详细介绍变量的运算。
